> 自己制作的一些小玩意，希望你喜欢。

这里收纳我随手记下的点子、实验结果和小作品。**每个想法一个目录**，想到就记、做了就打勾，
不追求完成度，只追求让想法有个落脚的地方。

## 目录约定

```
.
├─ README.md              # 这份清单（新想法直接加一行）
├─ ideas/                 # 每个想法一个目录，目录名 = 编号-简短英文名
│  └─ 001-example/
│     ├─ README.md        # 这个想法：想解决什么、怎么做、当前进度
│     └─ ...              # 代码、草稿、素材
└─ notes/                 # 零散笔记、参考链接
```

## 怎么加一个新想法

1. 新建目录 `ideas/NNN-简短英文名/`
2. 在里面写一个 `README.md`，三句话即可：**想做什么 / 为什么 / 下一步**
3. 回到本文件，在"想法清单"加一行
4. 提交（commit message 用中文没问题）
